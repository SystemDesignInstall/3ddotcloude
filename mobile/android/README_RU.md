# Spatial Capture — Android 0.1.0-preview.1

Первый самостоятельный клиент съёмки для Spatial Platform. Это предварительная версия для проверки на реальном телефоне, не измерительный прибор.

## Что работает в коде

- Камера ARCore, проверка поддержки Depth API, запрос разрешения и установки Google Play Services for AR.
- Цветные точки поверх камеры, отбор Raw Depth с confidence >= 128/255, диапазон 0,3–5 м.
- Накопление до 300 000 точек; одна лучшая по confidence точка в ячейке 2,5 см. Это разрешение сетки, не точность измерения.
- До 3 новых кадров глубины в секунду; очередь ограничена одним обрабатываемым кадром.
- Автоматическая остановка при 900 кадрах, 512 МиБ записанных payload, 300 000 точках или малом свободном месте.
- Сохранение при нажатии «Стоп / сохранить» и при уходе приложения в фон.
- Экспорт binary little-endian PLY и ZIP через системный выбор места сохранения.
- Список ранее записанных сканов. Неэкспортированные записи удаляются при удалении приложения.
- Проверка ZIP и восстановление облака на ПК: `desktop/import_scan.py`, Python 3.10+, без дополнительных пакетов.

## Проверка на телефоне

1. Установить APK. При необходимости Android предложит разрешить установку для приложения, через которое открыт APK.
2. Разрешить камеру; установить/обновить Google Play Services for AR, если предложено.
3. Нажать «Начать». Обойти небольшой неподвижный предмет или угол комнаты при хорошем освещении. Перемещать телефон в пространстве, не только вращать.
4. Убедиться, что счётчики кадров и точек увеличиваются, цвета совпадают с поверхностями.
5. Нажать «Стоп / сохранить», затем «Сохранить PLY». Выбрать папку Downloads или другое место.
6. Сохранить также «Данные ZIP» — это исходная запись для дальнейшей обработки.
7. Передать PLY на ПК и открыть в просмотрщике облаков. Проверить ориентацию и несколько расстояний рулеткой.
8. Проверить уход в фон во время записи, возврат и экспорт предыдущего скана через «Мои сканы».

Телефон без ARCore Depth получает понятное сообщение. Фотограмметрический режим без Depth пока не реализован. Полностью проверить сканирование без физического телефона невозможно.

## Обработка ZIP на Windows

Установить Python 3.10+ либо использовать уже установленный. Перетащить ZIP на `desktop/IMPORT_SCAN_WINDOWS.bat`.

Либо выполнить:

```powershell
py -3 desktop/import_scan.py scan.zip scan_imported
```

Выход: `cloud.ply`, `images/`, `trajectory.json`, `capture/` с неизменённой исходной записью и `import_report.json`. Существующая выходная папка не перезаписывается. Незавершённая сессия восстанавливается из полностью записанных кадров автоматически; параметр `--rebuild` принудительно пересобирает облако.

Это подготовка данных для платформы. Записи в Core, Scene, CAS и автоматическое исправление траектории не выполняются. Коррекция через RTAB-Map/Open3D/COLMAP — следующие этапы, не функции этой сборки.

## Сборка

Открыть эту папку в Android Studio либо установить JDK 17 и Android SDK (platforms;android-35, build-tools;35.0.0, platform-tools), принять условия SDK через sdkmanager. Указать SDK в ANDROID_HOME или local.properties.

```powershell
.\gradlew.bat :core:check :app:assembleDebug :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Debug APK подписан ключом разработчика среды сборки; при пересборке на другом компьютере подпись будет другой. Перед удалением старой версии экспортировать сканы.

```bash
python -m unittest discover -s desktop -v
```

## Ограничения

Глубина и масштаб оценены ARCore и зависят от устройства и сцены. Нет проверенной метрической точности, глобальной коррекции дрейфа, сшивки независимых сессий, построения сетки, автозагрузки на сервер и просмотра сохранённого облака с произвольной камеры внутри телефона. Во время съёмки доступен AR-предпросмотр. Фактическая производительность и нагрев требуют проверки на телефоне.

Исходные кадры не следует путать с необработанным сигналом сенсора: сохраняется CPU YUV-изображение, которое предоставляет ARCore, без дальнейших потерь (NV21 + gzip), и отдельная JPEG-копия для фотограмметрии.
