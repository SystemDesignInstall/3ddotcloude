Проверка AMD OpenCL v2 — Windows x64

1. Распакуйте оба файла из архива в отдельную папку.
2. Запустите AMD_OpenCL_Test_v2.exe и дождитесь результата.
3. Пришлите файл AMD_OpenCL_Report_v2.txt, который появится рядом с программой,
   или снимок окна с результатом.

Проверка выполняет короткие расчёты на каждой записи GPU AMD в OpenCL. Даже
если одна видеокарта указана несколько раз, проверяются все записи отдельно.
Программа не меняет драйверы, не требует прав
администратора, не использует фотографии и не отправляет данные в сеть.

Это диагностика видеодрайвера. Её успех ещё не доказывает, что реконструкция
фотографий на AMD работает: для этого нужна отдельная проверка движка.
