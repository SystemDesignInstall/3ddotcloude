# AMD на Windows: состояние исследования

Целевая конфигурация проверки: Windows 10 Pro 22H2 (19045.4894), Radeon RX 7900 XTX
(`gfx1100`). Отчёт пользователя перечислил `gfx1036`, `gfx1100`, `gfx1036`,
`gfx1100`; прежняя диагностика остановилась на неоднозначном выборе и не выполнила
вычисление. В отчёте версии 2 тесты буфера и изображений прошли на всех четырёх
записях, включая обе записи `gfx1100`: платформы/устройства `0/1` (AMD-APP 3683.0)
и `1/1` (AMD-APP 3652.0). Это две записи OpenCL; их соответствие физическим
устройствам по одному имени определить нельзя.

## Проверенное

- Основной тестовый фотопроцессинг `pycolmap` + OpenMVS выполняется на CPU.
- Windows-релиз COLMAP-CL 1.5 запускается с собственным каталогом `lib` и поддерживает
  команды `patch_match_stereo` и `stereo_fusion`. Релиз основан на COLMAP 3.6.
- На Windows CI этот COLMAP-CL прочитал тестовую сцену от `pycolmap` 4.2.1 и перешёл
  к первому изображению. Программная реализация PoCL 7.2 на CPU не смогла
  скомпилировать ядро OpenCL: `_cl_read_imagef` / `_cl_write_imagef` не объявлены.
  Плотное облако в этом опыте не получено. Принудительный стандарт OpenCL 1.2 не помог.
  [Журнал проверки](https://github.com/SystemDesignInstall/3ddotcloude/actions/runs/41189033126).
- В Linux отдельный тест PyOpenCL с программным PoCL 3.0 успешно выполнил чтение и
  запись изображения. Это не проверка Windows, RX 7900 XTX или полного COLMAP-CL.
- На компьютере пользователя малые тесты изображений и буфера OpenCL прошли для
  обеих записей `gfx1100`. Работа COLMAP-CL и построение плотного PLY на AMD
  остаются непроверенными до запуска полного эксперимента на устройстве.

COLMAP-CL скачивался только во временную CI-среду из его официального релиза. Для
повторяемости проверяется SHA-256 `0439d39d1231b7a6cd3b521f9c5ca327d9bec1c88084b38af36c942256ec1750`,
вычисленный при исследовании; опубликованного разработчиком SHA-256 не найдено.
Исходники изменённого движка и лицензия самого форка в репозитории не обнаружены.
Компонент не включён в поставку и не принят как production backend.

## Проверка реального устройства

`amd_opencl_diagnostic.py` — отдельный тест драйвера: выбирает GPU AMD, выполняет
небольшое чтение/запись изображения через OpenCL и сохраняет результаты и версию
драйвера. Успешная диагностика подтверждает выполнение этого небольшого ядра,
но не проверяет ядра COLMAP-CL, полную реконструкцию, качество или производительность.
Полную реконструкцию нужно проверять отдельно на реальной карте пользователя.

AMD документирует HIP SDK 6.4.2 для Windows 10 22H2 и RX 7900 XTX, но отмечает
отсутствие поддержки CMake HIP Language в Windows SDK. Поэтому из наличия SDK не
следует работоспособность штатной HIP-сборки COLMAP на Windows:
[AMD system requirements](https://rocm.docs.amd.com/projects/install-on-windows/en/docs-6.4.2/reference/system-requirements.html),
[AMD component support](https://rocm.docs.amd.com/projects/install-on-windows/en/docs-6.4.2/reference/component-support.html).
