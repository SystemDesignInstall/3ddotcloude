Spatial Photo Cloud — экспериментальная версия Windows x64 (AMD OpenCL и CR2)

1. Распакуйте весь архив в отдельную папку. Папка _internal должна находиться
   рядом с SpatialPhotoCloud.exe. Устанавливать Python не нужно.
2. Запустите SpatialPhotoCloud.exe и выберите «Плотное облако — AMD OpenCL
   (эксперимент)». Нажмите «Установить COLMAP-CL для AMD». Программа скачает
   внешний релиз COLMAP-CL 1.5 с GitHub, проверит фиксированную контрольную сумму
   и распакует его отдельно в профиле пользователя. Фото в сеть не отправляются.
3. Для первой проверки выберите папку test-photos из архива и отдельную папку,
   куда сохранить результат. Нажмите «Построить облако». Программа проверит
   AMD GPU, затем попытается построить на ней плотное облако. Пришлите из папки
   результата report.json и colmap-cl.log, даже если обработка завершилась ошибкой.
4. Если проверка успешна, можно выбрать свою папку CR2, JPG, PNG или TIFF.
   Кнопка «Открыть построенное облако» сразу откроет результат. Если PLY уже
   построен раньше, нажмите «Открыть готовый PLY…»: фото обрабатывать повторно
   не нужно. Откроется отдельное окно Edge или Chrome без вкладок браузера.
   Файл считывается локально через 127.0.0.1 и не отправляется в интернет.
5. «Полёт» включает движение W/S/A/D и Q/E. «Масштаб и измерение» позволяет
   выбрать две точки и ввести известное расстояние. «Выровнять облако» включает
   поворот самого облака, сетку, вид спереди и сверху. Для CAD можно выбрать
   вертикальную ось Z. Кнопка «Сохранить положение в этот PLY» записывает
   изменения в открытый файл, без скачивания. Исходная резервная копия создаётся
   рядом, в папке .SpatialPhotoCloud-backups. Без калибровки масштаб остаётся
   в произвольных единицах. Можно также подготовить отдельный файл для скачивания.
   Сохранённые результаты можно импортировать в поддерживающую PLY программу.
   Окно локального просмотра загружает PLY, пока открыта основная программа.

Для CR2 программа сначала создаёт JPEG-копии в prepared_images внутри результата;
исходные файлы не меняются. Копии занимают дополнительное место на диске. При
наличии данных в RAW сохраняются модель камеры и фокусное расстояние. Подготовка
и поиск камер используют CPU; экспериментальный этап плотного облака использует
выбранную OpenCL GPU. Его работа на Radeon RX 7900 XTX пока не подтверждена.

Если AMD-эксперимент не работает, выберите «Плотное облако — CPU (OpenMVS)» и
нажмите «Установить OpenMVS» (официальный архив около 22 МБ). Кнопка «Остановить»
запрашивает остановку; частичные файлы остаются в папке результата. При обработке
CR2 остановка может произойти после завершения текущего файла.

Масштаб результата по одним фотографиям не определён. Это исследовательская
сборка без SLAM и интеграции с базой Spatial Platform. Качество облака зависит от
перекрытия фотографий, освещения и фактуры сцены.

COLMAP-CL загружается отдельно; исходный код изменённого движка и его лицензия не
подтверждены. OpenMVS распространяется отдельно по AGPL-3.0. rawpy включает
LibRaw (LGPL/CDDL). Перед коммерческой поставкой нужен аудит всех лицензий и
бинарных зависимостей. Контрольная сумма COLMAP-CL зафиксирована в ходе исследования,
она не опубликована разработчиком движка.

Исходный код: https://github.com/SystemDesignInstall/3ddotcloude
