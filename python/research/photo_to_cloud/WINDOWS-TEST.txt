Spatial Photo Cloud — тестовая версия для Windows x64

1. Распакуйте весь архив в отдельную папку. Папка _internal должна находиться
   рядом с SpatialPhotoCloud.exe. Устанавливать Python не нужно.
2. Запустите SpatialPhotoCloud.exe. Для плотного облака нажмите «Установить
   OpenMVS»: программа скачает официальный архив OpenMVS 2.4.0 (около 22 МБ)
   и проверит его SHA-256. Установка происходит отдельно в профиле Windows.
3. Выберите папку фотографий и место сохранения результата. Нажмите
   «Построить облако». На CPU обработка может занять длительное время.
4. После завершения кнопка «Просмотр» откроет уменьшенную выборку облака в
   браузере без загрузки данных в интернет. Полное облако — файл dense.ply
   в папке результата. Его можно открыть, например, в CloudCompare.

Кнопка «Остановить» прерывает обработку; частичные файлы остаются в папке
результата и не считаются завершённым облаком.

Фотографии в проект не копируются. Масштаб по одним фотографиям не проверен.
Это исследовательская сборка без SLAM и интеграции с базой Spatial Platform.
Плотное облако по умолчанию строится на CPU, даже если установлена AMD GPU.
AMD-режим требует отдельную совместимую HIP-сборку COLMAP и пока не проверен
на реальной AMD-видеокарте.

OpenMVS распространяется отдельно по AGPL-3.0; его коммерческая поставка
требует проверки лицензии. COLMAP/pycolmap — BSD-3-Clause, Pillow — MIT-CMU,
NumPy — BSD-3-Clause. Бинарная сборка содержит сторонние зависимости; перед
коммерческой поставкой нужен полный аудит лицензий и комплектующих.

Исходный код и инструкция:
https://github.com/SystemDesignInstall/3ddotcloude
