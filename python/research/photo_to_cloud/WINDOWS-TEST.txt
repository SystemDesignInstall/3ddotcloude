Spatial Photo Cloud — экспериментальная версия Windows x64 (AMD OpenCL и CR2)

1. Распакуйте весь архив в отдельную папку. Папка _internal должна находиться
   рядом с SpatialPhotoCloud.exe. Устанавливать Python не нужно.
2. Запустите SpatialPhotoCloud.exe и дождитесь автоматической проверки CPU,
   оперативной памяти, OpenCL-видеокарты и установленных движков. Она выберет
   AMD OpenCL только после проверки GPU и COLMAP-CL; если этот путь недоступен,
   выберет плотный CPU-режим при установленном OpenMVS или разреженный CPU-режим.
   Если COLMAP-CL ещё не установлен, нажмите «Установить COLMAP-CL для AMD»;
   после установки программа повторно выполнит автоподбор. Скачивается внешний
   релиз COLMAP-CL 1.5 с GitHub, проверяется фиксированная контрольная сумма,
   движок распаковывается отдельно в профиле пользователя. Фото в сеть не отправляются.
   В режиме AMD OpenCL программа пробует выполнять сопоставление SIFT-фотографий
   на AMD GPU через OpenCL, затем строит карты глубины на GPU. Если OpenCL-
   сопоставление завершается ошибкой или не находит подтверждённых пересечений,
   база восстанавливается и сопоставление автоматически повторяется на CPU.
   Подготовка CR2, извлечение признаков, расчёт камер и слияние облака остаются
   на CPU; точные backend-этапы записываются в report.json.
3. Для первой проверки выберите папку test-photos из архива и отдельную папку,
   куда сохранить результат. Нажмите «Построить облако». Программа проверит
   AMD GPU, затем попытается построить на ней плотное облако. Пришлите из папки
   результата report.json и colmap-cl.log, даже если обработка завершилась ошибкой.
   Число потоков подбирается по физическим ядрам CPU, логическим процессорам и
   установленной памяти (ориентир — около 4 ГБ RAM на поток, максимум 16). Режим и потоки можно
   изменить вручную; повторный подбор запускается кнопкой «Подобрать автоматически».
   Выбранные компоненты и настройки записываются в report.json. Режим HIP остаётся
   ручным экспериментом и автоматически не выбирается.
4. Если проверка успешна, можно выбрать свою папку CR2, JPG, PNG или TIFF.
   Кнопка «Открыть построенное облако» сразу откроет результат. Если PLY уже
   построен раньше, нажмите «Открыть готовый PLY…»: фото обрабатывать повторно
   не нужно. Откроется отдельное окно Edge или Chrome без вкладок браузера.
   Файл считывается локально через 127.0.0.1 и не отправляется в интернет.
5. «XYZ и ноль» показывает оси исходного PLY и начало координат (0, 0, 0).
   «Показать (0, 0, 0)» переносит вид к нулю, если он далеко от облака.
   Через «Выбрать точку» и щелчок по облаку можно прочитать X/Y/Z этой точки
   в исходных координатах PLY. Без метрической отметки единицы остаются
   неизвестными; это начало координат файла, а не географическая привязка.
   «Полёт» включает движение W/S/A/D и Q/E. «Масштаб и измерение» позволяет
   выбрать две точки и ввести известное расстояние. «Выровнять облако» включает
   поворот самого облака, сетку, вид спереди и сверху. Для точной настройки
   введите угол рядом с ползунком или выберите шаг 1°, 0,1° либо 0,01° и
   нажимайте −/+. В поле угла также работают стрелки вверх/вниз. Для CAD можно выбрать
   вертикальную ось Z. Кнопка «Сохранить положение в этот PLY» записывает
   изменения в открытый файл, без скачивания. Исходная резервная копия создаётся
   рядом, в папке .SpatialPhotoCloud-backups. Без калибровки масштаб остаётся
   в произвольных единицах. Можно также подготовить отдельный файл для скачивания.
   Если надписи выглядят зеркально, сначала нажмите «Посмотреть с другой стороны».
   Если геометрия всё ещё отражена, включите «Отразить облако», сравните с
   фотографией и только затем сохраните. Зеркальное сохранение поддерживается
   для PLY с точками без дополнительных элементов; другие результаты не меняются.
   Сохранённые результаты можно импортировать в поддерживающую PLY программу.
   Окно локального просмотра загружает PLY, пока открыта основная программа.
6. Чтобы получить полигональный 3D-объект, нажмите в основном окне «Построить
   3D-сетку из PLY…», выберите плотный PLY с нормалями nx/ny/nz (обычно dense.ply)
   и сохраните результат под отдельным именем dense-mesh.ply. Построение Poisson
   выполняется на CPU выбранным числом потоков; исходное облако сохраняется.
   Готовая поверхность автоматически откроется в просмотрщике. Кнопка «Показать
   точки» переключит её обратно на облако. Возле результата появится
   dense-mesh.ply.report.json с числом вершин, граней и единицами масштаба.
   Это цветная сетка по облаку, без фототекстуры; Poisson может закрыть отверстия
   или добавить поверхность там, где фотографий было мало. Сначала проверьте
   форму в просмотрщике и импортируемой CAD/3D-программе. Если исходный PLY не
   содержит нормалей, построить сетку из него нельзя.
7. Для единого файла с фототекстурой нажмите «Экспортировать текстурированную
   модель GLB…». Выберите созданный mesh PLY, затем `dense_workspace` либо папку
   результата той же реконструкции и задайте отдельный `.glb`. Если установлен
   старый OpenMVS без `TextureMesh.exe`, приложение сообщит об этом; «Установить /
   обновить OpenMVS» поместит проверенную версию в новую соседнюю папку и сохранит
   старую. Готовый GLB лежит в выбранной папке и переносится одним файлом.
   Не текстурируйте mesh PLY после ручного поворота, отражения или изменения
   масштаба: его координаты перестанут совпадать с позами камер. Используйте
   нетронутую сетку из этой реконструкции. GLB сохраняет масштаб фотограмметрии,
   а не подтверждённые метры; не снятые камерой части могут не иметь текстуры.

Для CR2 программа сначала создаёт JPEG-копии в prepared_images внутри результата;
исходные файлы не меняются. Копии занимают дополнительное место на диске. При
наличии данных в RAW сохраняются модель камеры и фокусное расстояние. Подготовка
CR2, извлечение признаков, построение камер и слияние облака используют CPU.
AMD OpenCL применяется к сопоставлению SIFT и PatchMatch Stereo. Предыдущий полный
запуск на Radeon RX 7900 XTX подтвердил GPU для PatchMatch: зарегистрированы
146/146 снимков и построено 2 527 538 точек. Новое GPU-сопоставление SIFT пока
требует отдельной проверки на этом компьютере; его состояние и возможный возврат
к CPU будут указаны в report.json.

Если AMD-эксперимент не работает, выберите «Плотное облако — CPU (OpenMVS)» и
нажмите «Установить OpenMVS» (официальный архив около 22 МБ). Кнопка «Остановить»
запрашивает остановку; частичные файлы остаются в папке результата. При обработке
CR2 остановка может произойти после завершения текущего файла.

Масштаб результата по одним фотографиям не определён. Это исследовательская
сборка без SLAM и интеграции с базой Spatial Platform. Качество облака зависит от
перекрытия фотографий, освещения и фактуры сцены.

COLMAP-CL загружается отдельно; исходный код изменённого движка и его лицензия не
подтверждены. OpenMVS распространяется отдельно по AGPL-3.0. rawpy включает
LibRaw (LGPL/CDDL). Перед коммерческой поставкой нужен аудит всех лицензий и
бинарных зависимостей. Контрольная сумма COLMAP-CL зафиксирована в ходе исследования,
она не опубликована разработчиком движка.
